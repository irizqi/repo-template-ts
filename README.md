# Monorepo Template

Template monorepo Bun dengan Turbo untuk aplikasi dan shared packages.

## Struktur

- `apps/` aplikasi workspace.
- `packages/` shared packages.
- `packages/ui` shared UI primitives.
- `tools/eslint-config` shared ESLint flat config.
- `tools/typescript-config` shared TypeScript config.

## Commands

```sh
bun install
bun run dev
bun run build
bun run lint
bun run typecheck
```
